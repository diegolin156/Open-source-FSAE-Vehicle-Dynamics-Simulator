# Contributing

Thank you for your interest in contributing to the Open-source FSAE Vehicle Dynamics Simulator.

## How to contribute

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes.
4. Test the simulator and verify that existing functionality still works.
5. Commit your changes with a clear message.
6. Open a Pull Request describing what you changed and why.

## Reporting bugs

Before opening an issue, check whether it has already been reported.

When reporting a bug, include:
- A clear description of the problem.
- Steps to reproduce it.
- Expected behavior.
- Actual behavior.
- Browser and operating system, when relevant.
- Screenshots or simulation data when useful.

## Feature requests

Feature requests should explain:
- What you would like to add or improve.
- Why it would be useful for vehicle design or simulation.
- Any relevant equations, references, or engineering justification.

## Physics and engineering contributions

Changes to physical models should include the relevant equations, assumptions, references, or validation data whenever possible.

Please avoid introducing changes to engineering models without documenting the assumptions behind them.

## Pull Requests

Keep Pull Requests focused on a single improvement whenever possible.

A good Pull Request should:
- Explain the purpose of the change.
- Describe the main modifications.
- Mention any relevant tests or validation performed.
- Update the documentation when necessary.

## Code of conduct

Please be respectful and constructive when discussing the project. Technical disagreements are welcome when they are supported by clear reasoning and evidence.
